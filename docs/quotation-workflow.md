# Dream Events Quotation Workflow — V1.3

1. Build an event budget using Main Item → Sub Item → Detailed Item.
2. Mark the relevant budget structure as customer visible.
3. Set a customer selling price at Sub Item level, or leave it at zero and use Detailed Item customer prices.
4. Open Event → Quotation → Create Quotation.
5. The customer document displays Main Item headings and Sub Item prices only. Detailed internal items remain hidden.
6. Set issue date, validity, discount, payment terms and notes.
7. Create Version 1.
8. Preview and Print / Save PDF.
9. Mark the quotation Sent when delivered to the customer.
10. If requirements change, update the budget and create a New Revision. The previous active version becomes Superseded.
11. Mark the final customer-approved version Accepted. The event becomes Confirmed and the accepted total becomes the event confirmed value.
